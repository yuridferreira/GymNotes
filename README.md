# 🏋️‍♂️ GymNotes - App de gerenciamento de treinos

Aplicativo mobile desenvolvido em React Native com Expo, voltado para o gerenciamento de treinos.
Permite registrar exercícios, séries, repetições e pesos.

🚀 Tecnologias utilizadas

React Native (Expo)

AsyncStorage – para armazenamento local dos dados

React Navigation – navegação entre telas

React Hooks (useState, useEffect) – gerenciamento de estado e efeitos

⚙️ Funcionalidades principais

✅ Adicionar e listar treinos
✅ Excluir treinos individualmente
✅ Tela de configurações para personalização
✅ Dados salvos localmente no dispositivo

📱 Como executar o projeto
# Clonar o repositório
git clone https://github.com/yuridferreira/GymNotes

# Instalar dependências
npm install

# Rodar o app
npx expo start -c  


Depois, basta abrir no Expo Go (Android ou iOS) para visualizar o app.
